## 地狱维度 (The Nether)

#### 危险警告

地狱是一个充满危险的维度，拥有滚烫的岩浆和凶猛的怪物。进入前请确保装备充足！

### 维度介绍

地狱是Minecraft JS Edition中的下界维度，这里遍地都是岩浆湖，地形崎岖险峻。这里的怪物更加强大，但同时也蕴藏着珍贵的资源。

### 稀有资源

#### 远古残骸

稀有度：★★★★★

地狱中最珍贵的矿石，需要在Y=8-22层寻找。爆炸抗性极高，需要用钻石镐或更好的镐子开采。

只能在地狱生成

### 冶炼配方

熔炉冶炼

远古残骸 + 燃料 → 下界合金碎片

每个远古残骸可冶炼出1个下界合金碎片

### 合成配方

##### 下界合金锭

4 × 下界合金碎片  
4 × 金锭  
↓  
1 × 下界合金锭

在工作台中无序合成

#### 锻造台升级

使用锻造台可将钻石装备升级为下界合金装备：

- **钻石剑** + 下界合金锭 → **下界合金剑**
- **钻石镐** + 下界合金锭 → **下界合金镐**
- **钻石斧** + 下界合金锭 → **下界合金斧**
- **钻石锹** + 下界合金锭 → **下界合金锹**
- **钻石锄** + 下界合金锭 → **下界合金锄**
- **钻石头盔** + 下界合金锭 → **下界合金头盔**
- **钻石胸甲** + 下界合金锭 → **下界合金胸甲**
- **钻石护腿** + 下界合金锭 → **下界合金护腿**
- **钻石靴子** + 下界合金锭 → **下界合金靴子**

**✨ 下界合金装备特性：**

- 更高的耐久度
- 更强的攻击力
- 更好的保护效果
- 不会被岩浆烧毁
- 不会在火焰中消失
